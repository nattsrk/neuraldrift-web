5 · What changed (and nothing else)

  • Split into one HTML file per page; CSS, scripts, fonts, icons and media moved into separate files. Markup, CSS rules and scripts unchanged.
  • Soft cross-fade between pages added in CSS (@view-transition), standing in for the one-file build's in-page swap.
  • Site script: 11 small, listed edits, all about addresses and files: GE6 engine page opened from its own file; films keep the one-file rendition set (720p AV1 + H.264), now as files; in-page # links still scroll; #/ links go to the page; links from the GE6 engine page go to real addresses; media read from files, not the hidden store; menu groups and current-page marks compare addresses; pages come from the address bar, not #/ routes; start: show the page this address belongs to.
  • Each page has its own title, description, canonical link and share tags (taken from Vicky's per-page data). A sitemap.xml and robots.txt were added.
